# Travlr Getaways

## Overview
Travlr Getaways is a complete stack travel application that has been built utilizing the MEAN stack, which consists of MongoDB, Express, Angular, and Node.js. This application has been extended with a client-side website, along with an admin single-page application. This application allows users to view travel trips, while the admin side allows authenticated users to log in and manage the trips.

## Architecture
This project has utilized two different front-end development strategies. The client-side part has been built utilizing Express, HTML, JavaScript, and Handlebars templating with an MVC framework. This part has been implemented on the server-side, which is suitable for the client-side part, as it displays the information regarding the trips.

The admin part has been implemented utilizing Angular, which has enabled the development of a single-page application, resulting in a better user experience for the users. MongoDB has been used for the backend, which has been suitable for JavaScript-based applications, as it can store information in the form of documents.

## Functionality
JSON stands for JavaScript Object Notation, which differs from JavaScript, as JSON is a text-based data interchange format, while JavaScript is a programming language. In the context of this project, JSON has been used as a medium for communication between the front-end and the back-end, as it has been used for providing API information in JSON format for the client-side part, as well as the admin part.

Some of the refactoring activities that were carried out to illustrate this process include the refactoring of the static HTML page containing the travel information to a dynamic template using the Handlebars template engine. In addition, the Angular services and components were used to manage the admin part of the application. Through the creation of reusable UI components, the management of the application was achieved.

## Testing
In the context of a full-stack application, endpoints refer to the API URLs together with the corresponding HTTP request methods that define the action to be taken. Testing is a crucial process to ensure that the application allows the retrieval, addition, updating, and deletion of the relevant data.

The security aspect represents another dimension of the testing process. In this project, the testing process ensured the effectiveness of the user authentication process through the provision of a login feature. In addition, the process ensured that the admin routes were restricted to authenticated users. Finally, the process ensured that the application restricted the relevant functions to authorized users.
